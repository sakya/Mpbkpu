# Multi Platform Backup Utility
A multi platform backup utility with encryption and compression feature.
Supports local and remote file system.

A backup can be split among more destinations: every file is stored in one of them, the database in all of them.

Supported backup types:
- Full
- Incremental
- Differential

Supported remote file systems:
- FTP
- SFTP
- Dropbox
- MediaFire
- Mega
- Nextcloud
- OneDrive
